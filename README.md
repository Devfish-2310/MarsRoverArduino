# Regolith-X (Mars Exploration Rover)
A servo-assisted Mars mining rover prototype designed to navigate simulated Martian terrain, collect regolith, and transport resources using an integrated embedded control system.

Regolith-X combines a four-wheel-drive mobility platform, Arduino-based embedded control, Bluetooth wireless communication, and servo-actuated collection mechanisms into a single robotic system. The rover uses an Arduino Uno as the central processing unit, controlling four DC gear motors through L298N motor drivers and seven servo motors responsible for collection and chassis actuation.

Unlike conventional RC vehicles that only provide remote movement control, Regolith-X integrates mechanical automation into the control architecture. The rover performs coordinated movement sequences involving chassis adjustment, regolith collection, storage, and return navigation. The system demonstrates the integration of mechanical design, electrical hardware, and embedded software for planetary resource extraction applications.

Potential applications include robotic mining systems, planetary exploration vehicles, hazardous environment operations, and autonomous resource collection platforms.

## How it Functions

The rover uses an Arduino Uno as the central microcontroller, coordinating wireless communication, motor control, and servo actuation. A 3S 11.1V LiPo battery supplies power to the system, with the Arduino powered through the VIN pin and the L298N motor driver receiving power through its 12V input. Two DC voltage regulators step down the battery voltage to approximately 6.2V to safely power the servo motors.

The control architecture consists of three main subsystems: locomotion, collection, and ride-height adjustment. The Arduino receives wireless commands from an Android application through an HC-05 Bluetooth module connected via serial communication. Bluetooth TX/RX communication is connected to Arduino pins 0 and 1, allowing incoming character commands to be processed using `Serial.read()` within the main control loop.

The locomotion system uses four hobby gearbox DC motors configured as a four-wheel-drive platform. Initially, each motor was independently connected to the L298N motor driver, requiring separate control signals and increased wiring complexity. The final design instead connects the left-side motors in parallel and the right-side motors in parallel, reducing the required control connections while maintaining identical movement functionality. The L298N motor driver receives directional signals from Arduino digital pins 8, 9, 10, and 11, controlling motor polarity and enabling forward, reverse, left, and right movement.

The collection mechanism uses servo motors to perform mechanical manipulation tasks. The front and rear collection arms are controlled through servo pairs connected to Arduino digital pins 6 and 7 respectively. These servos rotate synchronously to position the collection arms and optimise material retrieval. A continuous rotation servo is used within the collection system to wind and unwind the attached mechanism, allowing the arms to retract and extend.

The adjustable ride-height system is driven by four high-torque servo motors arranged into front and rear pairs. By rotating simultaneously, the servos modify the rover’s vertical position through a geared lifting mechanism, allowing the chassis height to be adjusted depending on terrain conditions. Servo movement is controlled through PWM signals generated by the Arduino using the `Servo.h` library.

The Arduino firmware was programmed in C++ using the Arduino IDE. During initialisation, motor pins are configured as outputs using `pinMode()`, servo objects are attached using `attach()`, and Bluetooth serial communication is established using `Serial.begin(9600)`. The main loop continuously monitors incoming Bluetooth commands and executes corresponding control functions.

Motor commands are interpreted as single-character inputs:
- `F` — activates forward movement by driving both left and right motor pairs forward
- `B` — reverses motor direction for backward movement
- `L` — rotates the rover left by reversing the left motors and driving the right motors forward
- `R` — rotates the rover right by reversing the right motors and driving the left motors forward
- `S` — stops all motors by setting control pins LOW
- `W` — lowers the rover ride height through servo adjustment
- `U` — raises the rover ride height through servo adjustment
- `K` — adjusts rear collection servos
- `P` — adjusts front collection servos

Before final assembly, all electrical connections were soldered to improve mechanical reliability and prevent wire disconnection during rover movement. The final integrated system places the Arduino Uno, L298N motor driver, Bluetooth module, battery, and voltage regulators within the upper electronics compartment, while the motor and collection mechanisms are mounted within the lower chassis structure.
